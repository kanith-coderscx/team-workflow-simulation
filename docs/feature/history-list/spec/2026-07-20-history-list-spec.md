# Spec: ดูรายการย้อนหลัง + ลบรายการ (history-list)

- **slug:** `history-list`
- **priority:** p2
- **วันที่:** 2026-07-20
- **ผู้เขียน:** BA/SA

## สรุปงาน (Summary)

หน้ารายการย้อนหลังที่แสดงรายการรายรับ/รายจ่ายทั้งหมดจาก `localStorage` คีย์ `tws.transactions` เรียงจากใหม่ไปเก่า (ล่าสุดอยู่บนสุด) แต่ละแถวแสดง วันที่, ประเภท, หมวดหมู่, จำนวนเงิน และบันทึกช่วยจำ (ถ้ามี) พร้อมปุ่มลบรายการทีละรายการ เมื่อลบ ระบบถามยืนยันก่อน แล้วจึงลบออกจาก `localStorage` และหน้าจอทันที

## หมายเหตุ/ขอบเขต (Scope notes)

- อ่านข้อมูลจาก schema เดียวกับที่ `add-transaction` เขียนไว้ (คีย์ `tws.transactions`) — ไม่นิยาม field ใหม่
- การเรียงลำดับใช้ `date` (ISO `YYYY-MM-DD`) เป็นหลัก ใหม่→เก่า; หากวันเดียวกัน ให้เรียงตามลำดับที่เพิ่มทีหลังขึ้นก่อน (อิง `id` ที่สร้างจาก timestamp)
- ลบได้ทีละรายการเท่านั้น — ยังไม่มีลบหลายรายการพร้อมกัน และยังไม่มีแก้ไข (edit) ในเฟสนี้
- ไม่มีการ undo หลังยืนยันลบ
- ถ้ายังไม่มีรายการเลย ต้องแสดง empty state ไม่ใช่หน้าว่างเปล่า

## ข้อความบนหน้าจอที่ต้องตรงเป๊ะ (On-screen copy — ห้ามพิมพ์ต่างจากนี้)

- ข้อความเมื่อยังไม่มีรายการ (empty state): «ยังไม่มีรายการ»
- ปุ่มลบในแต่ละแถว: «ลบ»
- ข้อความยืนยันก่อนลบ: «ยืนยันการลบรายการนี้?»

## Acceptance Criteria

- [ ] เมื่อผู้ใช้เปิดหน้ารายการย้อนหลังขณะที่ยังไม่มีรายการใด ๆ → ระบบแสดงข้อความ «ยังไม่มีรายการ»
- [ ] เมื่อมีรายการอยู่แล้วและผู้ใช้เปิดหน้ารายการย้อนหลัง → ระบบแสดงทุกรายการ โดยรายการที่วันที่ใหม่กว่าต้องอยู่ด้านบน (เรียงใหม่→เก่า)
- [ ] เมื่อผู้ใช้ดูแต่ละแถว → ระบบแสดง วันที่, ประเภท (รายรับ/รายจ่าย), หมวดหมู่, จำนวนเงิน และปุ่มที่มีข้อความ «ลบ»
- [ ] เมื่อผู้ใช้กดปุ่ม «ลบ» ที่แถวหนึ่ง → ระบบแสดงข้อความยืนยัน «ยืนยันการลบรายการนี้?» ก่อนลบจริง
- [ ] เมื่อผู้ใช้ยืนยันการลบ → แถวนั้นหายไปจากหน้าจอทันที และรายการที่เหลือยังคงเรียงใหม่→เก่าถูกต้อง
- [ ] เมื่อผู้ใช้ลบรายการแล้วกด Refresh (F5) → รายการที่ถูกลบต้องไม่กลับมา (ยืนยันว่าลบออกจาก `localStorage` จริง)
- [ ] เมื่อผู้ใช้ลบรายการจนไม่เหลือเลย → ระบบกลับไปแสดงข้อความ «ยังไม่มีรายการ»

## Test steps (สำหรับผู้ทดสอบที่คลิกในเบราว์เซอร์ ไม่ต้องเป็นนักพัฒนา)

1. เปิด URL ของระบบที่ deploy แล้วในเบราว์เซอร์ (Chrome) ไปที่หน้ารายการย้อนหลัง โดยเริ่มจากสถานะที่ยังไม่มีรายการ (หากมีข้อมูลค้าง ให้ลบให้หมดก่อน) → ต้องเห็นข้อความ «ยังไม่มีรายการ»
2. ไปเพิ่มรายการ 3 รายการต่างวันกัน เช่น วันที่ `2026-07-10`, `2026-07-18`, `2026-07-21`
3. กลับมาที่หน้ารายการย้อนหลัง → ตรวจว่ารายการวันที่ `2026-07-21` อยู่บนสุด และ `2026-07-10` อยู่ล่างสุด
4. ตรวจว่าแต่ละแถวแสดง วันที่ ประเภท หมวดหมู่ จำนวนเงิน และมีปุ่มที่เขียนว่า «ลบ»
5. กดปุ่ม «ลบ» ที่แถวใดแถวหนึ่ง → ต้องเห็นข้อความยืนยัน «ยืนยันการลบรายการนี้?»
6. กดยืนยัน → ตรวจว่าแถวนั้นหายไปทันที และแถวที่เหลือยังเรียงใหม่→เก่าถูกต้อง
7. กด Refresh (F5) → ตรวจว่าแถวที่เพิ่งลบไม่กลับมา
8. ลบรายการที่เหลือทั้งหมด → ตรวจว่าหน้าจอกลับไปแสดงข้อความ «ยังไม่มีรายการ»
